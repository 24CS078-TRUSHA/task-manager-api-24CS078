# Task Manager API

This is the backend for the Practical 6 Full Stack Task Management Application.

The backend is built using:

- Node.js
- Express.js
- MongoDB
- Mongoose
- CORS

The API provides CRUD operations for managing tasks.

---

## Technologies Used

- Node.js v18+
- Express.js
- MongoDB
- MongoDB Compass
- Mongoose
- dotenv
- CORS
